# Language

Write all authored project content in English, including:

- Documentation, README files, and project context.
- Rules, skills, role descriptions, plans, and reviews.
- Code identifiers, comments, and documentation comments.
- Log messages, error messages, test descriptions, and example text.

Apply this rule to new content and content rewritten during a task. Preserve
external API identifiers, quoted source material, and user or model messages
when their original language is part of the data being handled.
